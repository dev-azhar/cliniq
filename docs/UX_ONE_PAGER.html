Premium warm-ivory canvas

One patient, many desks. ClinIQ follows a single patient across the whole care journey — check-in → triage → doctor → lab → pharmacy → billing — with live coordination and advisory AI at every step, on a calm, premium clinical surface.

Patient Journey

Check-in› Reception› Triage · ESI› Doctor + AI› Lab› Pharmacy› Billing
  • An active-session card in the top bar carries the current patient across every desk.
  • Command Center mirrors it all live — queue load, alerts, event stream, audit trail.

UX Principles

  • Clarity over decoration — high-contrast data, tabular numerals, quiet headers.
  • Ambient awareness — real-time queues & events, no manual refresh.
  • Advisory AI — every AI output is labeled (“✦ Live”), explainable, never auto-applied.
  • Progressive disclosure — collapsible nav, expandable sessions, modal deep-dives.
  • Accessible by default — focus rings, semantic roles, color never used alone.

Shell & Navigation

  • Left sidebar — role-colored nav; active item = tinted pill + accent bar.
  • Top bar — brand tile, connection status, waffle app launcher, active-session card.
  • Content — pattern of KPI metric row → work panel(s) → live rails; fades in on route change.
